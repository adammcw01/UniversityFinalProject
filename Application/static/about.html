About


This website is an example user interface for a project undertook as part CSC3002 Generation of Sheet Music Notation for Piano Using Deep Learning. This project was developed by Adam McWilliams, the source code for this project can be found at: csc3002-40266924

The purpose of this project is to generate musical sheet music notation, also known as a score. From a musical recording.

This application works by implementing a convolutional neural network using the Keras library on the TensorFlow framework. When a recording is uploaded to the server it is split into individual notes based on the tempo. The app converts these notes into spectrogram's using a short-time Fourier transform.

The notes you see in the final result are the predictions made by the model on the spectrogram's.

Any information uploaded to the server is deleted after the final score has been generated.

For a more detailed tutorial on how to use this application please see the guide page.

This deep learning model was trained based on data found in the NSynth dataset which can be found at https://magenta.tensorflow.org/datasets/nsynth

To learn more about digital representation of music, please check out MIDI.
